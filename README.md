# 序列 · 加拿大28个人统计前端

GitHub Pages仅发布静态界面，后台运行在独立服务器。访问数据和修改设置需要站点专用密码。本仓库不包含开奖数据库、访问密码、通知密钥或服务器凭据。

功能：两套自动方案、每日回测、连续未中统计、480/516/720号码生成、提醒设置与未启用的倍投草稿。

默认规则：有兄弟方案连续两期未中，从下一期切为无对子720组；无对子命中后下一期恢复原兄弟方案。4=480组，5=516组（增加1/9关系）。状态跨日延续，日统计按北京时间切段。

`dist/`为已验证的静态成品，无依赖安装和服务端运行要求。工作流使用GitHub Actions作为唯一Pages发布来源。

页面与API通过HTTPS连接。跨站登录凭据仅保留在当前页面内存中，刷新需重新登录；不把访问令牌写入URL、localStorage或公开仓库。飞书/Bark配置只写入后台，浏览器不回显密钥。

仅用于个人历史数据统计、号码生成与通知。倍投执行尚未启用。
